§135.267 Quick Reference

Rolling 24-Hour Flight Time

Single pilot: max 8 hours in any consecutive 24-hour window.
Dual pilot: max 10 hours.
The 24-hour window is anchored at your Release Time and looks back 24 hours. Each leg's flight time is the Hobbs delta plus 0.2 hours for ground operation.

10-Hour Look-Back Rest

Before any flight segment, the pilot must have received at least 10 consecutive hours of rest in the 24 hours preceding the completion of that segment. This tracker checks whether a qualifying rest period ended within the 24-hour lookback window.

14-Hour Duty Day

Total duty period (Show Time to Release Time) must not exceed 14 hours. The tracker flags any duty period over 14 hours.

Quarterly Rest Requirement

Each pilot must receive at least 13 24-hour rest periods per calendar quarter. Check the "24-hour rest day" box on any day you had no duty. The dashboard shows your running count.

Exceedance Rest Multiplier

If flight time is exceeded (e.g., due to weather or an unforeseen delay):
< 30 min over → 11 hrs rest required
30–60 min over → 12 hrs rest required
> 60 min over → 16 hrs rest required

How to Use This Tool

Enter one row per flight leg. For a multi-leg day, Show Time and Release Time are the same across legs; Off/On Blocks Hobbs change each leg. Rest fields only need to be filled on the last leg of the day. Mark 24-hr rest days with the checkbox (no flight fields needed).

Off/On Blocks: Enter the Hobbs meter reading (e.g. 12345.6) at engine start and shutdown. The tracker automatically adds 0.2 hours to each leg's Hobbs delta to account for ground ops time. Example: Off Blocks 12345.6, On Blocks 12347.1 → Hobbs delta 1.5 + 0.2 ground operations = 1.7 hrs logged.
